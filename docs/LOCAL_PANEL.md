# 本机面板使用

面板流程是**准备服务 → 导入账号 → 获取连接信息**。把仓库口令发给 Agent 后，它会继续按自身能力接好并做短任务核对；“接给你自己”已经明确了目标，无需再选一次。单独安装面板和选择模型不会自动修改客户端设置。

账号连接与协议转换由独立安装的社区组件 Antigravity Tools 处理。本仓库提供本机界面、组件生命周期和兼容 API，不提供账号或额度。

## 打开面板

需要 **Python 3.11+**。让能操作本机的 Agent 安装并启动，或双击 `启动面板.command`（Mac）／`启动面板.bat`（Windows）。启动器检查已有 Python；缺少时由 Agent 协助安装，也可使用 [Python 官方下载](https://www.python.org/downloads/)。

```sh
python3 scripts/kit_app.py --open
```

Windows 可用 `py -3 scripts/kit_app.py --open`。默认面板地址是 **http://127.0.0.1:8787**。原有 CLI 支持 Python 3.10+，新面板需要 3.11+。

## 1. 准备服务

点击「准备并启动」。Mac 优先使用已安装的 5.0.3，没有则下载对应架构的上游归档；Linux 使用对应架构的 AppImage，并需具备所需系统库。下载核验固定 SHA256 后，组件使用独立数据目录启动。

Windows 首次按提示运行[上游 5.0.3 安装器](https://github.com/lbjlaq/Antigravity-Manager/releases/tag/v5.0.3)，然后回面板继续。不会静默安装或关闭系统安全功能。

面板默认监听 `127.0.0.1:8787`，独立组件监听 `127.0.0.1:8879`。遇到端口占用会保留原服务；启动和目录查询不发模型生成请求，组件自动预热关闭。

## 2. 导入账号

将你授权使用的完整 Refresh Token 填入本机页面，点击「导入账号」。只填 `1//` 开头的 Token，不填整行账号密码，也不把它当作客户端 API Key。

输入提交后清空，内容交给本机所选 Manager；面板不把 Token 写入自身状态或请求日志。Manager 会在私有数据目录保存维持登录所需的凭据，不要分享该目录。已有登录的 Manager 可以直接复用，无需再次导入。

页面可查看账号返回的权益、刷新额度或移除账号。移除会删除对应账号资料；型号可用性以当前目录及实际请求为准。

## 3. 获取连接信息，让 Agent 完成接入

选择目录里的完整模型 ID，使用页面提供的：

| 字段 | 用途 |
| --- | --- |
| API Base URL | 默认 `http://127.0.0.1:8787/v1`；若客户端要求完整 Chat URL，则用 `/v1/chat/completions` |
| Model | 当前目录中的完整模型 ID |
| API Key | 点击页面的密钥复制入口，只粘贴到本机客户端密钥框 |

选择模型只保存面板选择。接手的 Agent 按你已明确的目标（包括“接给你自己”）、[接手流程](AGENT_HANDOFF.md)和[客户端指南](CLIENTS.md)备份并配置。明确要替换主模型时使用原生自定义 API；否则用外援保留原默认。有命令工具时可直接用 `ask`，不必先装 MCP。Codex 是常用选项；Muse、GrokBot、WorkBuddy、豆包工作、DSH 等按实际能力接入，列出名称不代表已经逐个通过实测。

页面短测是可选操作，会发送一次短请求并消耗额度。默认请求串行、没有固定 120 秒等待；上游返回明确的等待时间时遵守提示，未提供时不推测恢复时间，不自动重试或换模型。已经使用的外部代理可能有自己的等待设置。

模型目录或短测通过不能替代客户端真实任务。仓库口令已要求短任务核对时，Agent 应继续执行并检查结果；用户只要求部署或明确不测试时，则说明尚未实测。

## 已有 Manager

让 Agent 使用你明确授权的配置文件路径。例如：

```sh
python3 scripts/kit_app.py --connect-manager-config "$HOME/.antigravity_tools/gui_config.json" --open
```

示例路径需按实际安装确认。面板只读取网关端口和鉴权字段，不读取账号 Token；首次显式指定后，本机私有状态会记住选择。不要打印整份配置。

已有本机串行代理可通过 `--inference-origin http://127.0.0.1:8046` 显式使用；新安装不必额外部署它，也不要把面板自身 `8787` 设成上游。面板不会停止复用的原服务。

## 运行位置与关闭

`127.0.0.1` 仅指当前电脑。云端 Agent 不能直接访问你电脑上的面板；应在其实际运行环境部署，或使用已有的鉴权 HTTPS 网关，本项目不会自动公开你的电脑。

保持启动窗口运行；相关任务结束后按 `Ctrl+C` 停止面板及它自己启动的 Manager。若使用后台服务，按 Agent 留下的方法停止。仅关闭浏览器标签不会停服务，复用的现有 Manager 也不会被关闭。

私有数据默认位置：

| 系统 | 位置 |
| --- | --- |
| macOS | `~/Library/Application Support/Gemini Agent Kit/` |
| Windows | `%LOCALAPPDATA%\Gemini Agent Kit\` |
| Linux | `~/.local/share/gemini-agent-kit/` |

账号、密钥、运行状态与日志属于私有数据，不上传仓库或作为公开素材。目标客户端需要恢复时，只撤销本次配置，保留用户后续修改。
